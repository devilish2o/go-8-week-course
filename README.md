# Go Programming — 8-Week Course

A practical, 30-minute-per-day Go learning path (12 November 2026 – 6 January 2027).

## Start here
1. Read [the complete 56-day syllabus](syllabus/README.md).
2. Import [the calendar](calendar/go-8-week-course.ics) into Google Calendar.
3. Build the final project, [hostwatch](projects/hostwatch/README.md), as you learn.

## Course rhythm
- 5 min: recall yesterday's ideas.
- 10 min: read the day's resource.
- 15 min: type, run, modify and test code.
- Use `gofmt`; commit each weekly milestone.

## Weekly outcomes
| Week | Focus | Outcome |
|---|---|---|
| 1 | Fundamentals | Small Go programs and CLI |
| 2 | Data structures and packages | Host inventory |
| 3 | Interfaces, errors, tests | Tested checker |
| 4 | Concurrency and networking | Concurrent endpoint checker |
| 5 | JSON, files, flags, logging | Usable hostwatch CLI |
| 6 | HTTP server and API | Local monitoring API |
| 7 | SQLite, Linux, ntfy | End-to-end checks |
| 8 | Polish and deployment | Demonstrable portfolio project |
