# Week 1 — Getting started and Go fundamentals

**Daily session:** 30 minutes (5 min recall, 10 min study, 15 min coding).

## Daily targets

1. **12 Nov — Install Go and meet the toolchain**
   - Target: Install Go; run go version/go env; create and run Hello World.
   - Study: https://go.dev/doc/tutorial/getting-started

2. **13 Nov — Packages, imports and main**
   - Target: Split a small program into main and helper package.
   - Study: https://go.dev/tour/basics/1

3. **14 Nov — Variables, constants and types**
   - Target: Build MB↔GB and Celsius↔Fahrenheit converters.
   - Study: https://go.dev/tour/basics/11

4. **15 Nov — Functions and multiple return values**
   - Target: Write conversion and disk-percentage functions; return value plus error.
   - Study: https://gobyexample.com/functions

5. **16 Nov — Control flow and loops**
   - Target: Practise if/switch/for/range/defer; build a repeating menu.
   - Study: https://go.dev/tour/flowcontrol/1

6. **17 Nov — Strings, formatting and user input**
   - Target: Use fmt, Scanner and strconv; accept a hostname and print a report.
   - Study: https://gobyexample.com/string-functions

7. **18 Nov — Weekly review: mini CLI**
   - Target: Build a 3-command CLI with validation and helpful errors; run gofmt.
   - Study: https://gobyexample.com/command-line-arguments

## Weekly outcome
Write small Go programs and understand the toolchain.
