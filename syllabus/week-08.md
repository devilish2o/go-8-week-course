# Week 8 — Production polish and deployment

**Daily session:** 30 minutes (5 min recall, 10 min study, 15 min coding).

## Daily targets

1. **31 Dec — Project structure and clean design**
   - Target: Review packages, naming, interfaces and errors.
   - Study: https://go.dev/doc/effective_go

2. **1 Jan — Configuration and operational modes**
   - Target: Support one-shot/periodic modes and validate config.
   - Study: https://gobyexample.com/environment-variables

3. **2 Jan — Logging, metrics and observability**
   - Target: Add structured logs, counters and durations.
   - Study: https://go.dev/doc/diagnostics

4. **3 Jan — Build and cross-compile**
   - Target: Build Linux binary; inspect with file and ldd.
   - Study: https://go.dev/cmd/go/

5. **4 Jan — Deployment rehearsal**
   - Target: Use a test directory as normal user; do not change existing services/nginx.
   - Study: https://go.dev/doc/

6. **5 Jan — systemd service design**
   - Target: Draft an unprivileged unit for review; do not enable yet.
   - Study: https://www.freedesktop.org/software/systemd/man/latest/systemd.service.html

7. **6 Jan — Final assessment and demo**
   - Target: Run tests/race detector/build; demo CLI, API, history and ntfy.
   - Study: https://gobyexample.com/

## Weekly outcome
Polish, build and rehearse a safe deployment.
