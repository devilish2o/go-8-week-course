# Week 5 — JSON, files, CLI design and logging

**Daily session:** 30 minutes (5 min recall, 10 min study, 15 min coding).

## Daily targets

1. **10 Dec — JSON encoding**
   - Target: Encode/decode CheckResult with struct tags.
   - Study: https://go.dev/doc/tutorial/

2. **11 Dec — Read and write files**
   - Target: Save/load JSON; handle missing files and permissions.
   - Study: https://gobyexample.com/reading-files

3. **12 Dec — Command-line flags**
   - Target: Add --url, --timeout, --format and --output.
   - Study: https://gobyexample.com/command-line-flags

4. **13 Dec — Environment variables and configuration**
   - Target: Set precedence: flags, environment, defaults.
   - Study: https://gobyexample.com/environment-variables

5. **14 Dec — Structured logging**
   - Target: Use log/slog; never log secrets.
   - Study: https://pkg.go.dev/log/slog

6. **15 Dec — Time, tickers and periodic work**
   - Target: Run checks repeatedly and stop cleanly.
   - Study: https://gobyexample.com/tickers

7. **16 Dec — Weekly review: first usable CLI**
   - Target: Combine config, concurrency, JSON and slog into hostwatch.
   - Study: https://gobyexample.com/command-line-flags

## Weekly outcome
Build a practical CLI with JSON, configuration and logging.
